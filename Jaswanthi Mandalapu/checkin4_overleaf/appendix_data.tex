\subsection{What the datasets contain}
\texttt{summary.md} in the dataset-exploration folder counts the files the later runs actually load.
GSM8K has 1{,}319 test problems and 7{,}473 training problems.
Questions average 61 tokens.
Reference solutions average 3.2 calculation steps.
The gold answer that a confidence average would cover is 2.29 tokens on average, and every test answer is an integer.
No test question is duplicated, and none appears in the training split.
MATH-500 has 500 problems in both the DEER file and the Hugging Face release, with no missing items.
The grader accepts all 500 reference solutions.
Answer types are 313 integers, 97 expressions, 50 fractions, 23 tuples or intervals, 10 text or choice answers, and 7 decimals.

\subsection{State-dependent threshold}
\texttt{adaptive\_threshold\_heldout/results.md}.
Eight seeds, 30\% of the Check-In 3 questions held out, thresholds chosen on the other 70\%.
This is not the 1{,}000/500 training-trajectory experiment.
The policy family (a higher bar on the first checkpoint, a lower bar once an answer repeats, and no exit on an unfinished formula) was chosen after reading misses on these same logs, so the held-out gap is optimistic.
The README in that folder says so, and this report does not use the row as the final rule.
